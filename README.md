# RAG Application with LangChain, MongoDB Atlas, and Gemini LLM

This project is a **Retrieval-Augmented Generation (RAG)** application built using **LangChain**, **MongoDB Atlas Vector Search**, and **Google's Gemini LLM**. It allows users to upload datasets in multiple formats (`.txt`, `.pdf`, and `.csv`), store them as vector embeddings in MongoDB Atlas, and query them using natural language. The application provides two types of outputs: raw retrieval from vector search and an enhanced response generated by chaining the retrieval with a large language model (LLM). The front-end is powered by **Gradio**, providing an intuitive web interface.

## Features
- **File Upload**: Supports multiple file types (`.txt`, `.pdf`, `.csv`) for building a knowledge base.
- **Vector Storage**: Stores document embeddings in MongoDB Atlas Vector Search for efficient similarity-based retrieval.
- **Dual Output**:
  1. **Raw Retrieval**: Returns the most relevant document content using cosine similarity via MongoDB Atlas Vector Search.
  2. **Enhanced Response**: Chains the raw retrieval with Google’s Gemini LLM to generate an improved, context-aware answer.
- **Web Interface**: Built with Gradio, offering a simple UI for file uploads and querying.

## Architecture
The application follows a modular RAG architecture:
1. **Data Ingestion**:
   - Users upload files through the Gradio interface.
   - Files are processed using appropriate loaders (e.g., `PyPDFLoader` for PDFs, `TextLoader` for text files) from LangChain.
   - Documents are embedded using Google’s `embedding-001` model and stored in MongoDB Atlas Vector Search.
2. **Query Processing**:
   - Queries are embedded and searched against the vector store using cosine similarity.
   - **Raw Output**: The most relevant document content is returned directly.
   - **Enhanced Output**: The raw output is passed to the Gemini LLM (`gemini-1.5-pro-latest`) via LangChain’s `RetrievalQA` chain for refinement and additional context.
3. **Frontend**: Gradio provides tabs for uploading files and querying the knowledge base, displaying both outputs.

## Tech Stack
- **Python**: Core programming language.
- **LangChain**: For document loading, embeddings, and chaining with LLMs.
- **MongoDB Atlas**: Vector search database for storing and retrieving embeddings.
- **Google Gemini LLM**: For embeddings (`embedding-001`) and text generation (`gemini-1.5-pro-latest`).
- **Gradio**: Web interface for user interaction.
- **PyMongo**: MongoDB client for Python.

## Prerequisites
- Python 3.8+
- MongoDB Atlas account with a cluster set up (and vector search enabled).
- Google API key for Gemini LLM and embeddings.
- Required Python packages (listed in `requirements.txt`).
